# 📊 Admin Dashboard using Bootstrap

> 🖥️ **A responsive Admin Dashboard built with modern web development tools.**

A simple and responsive **Admin Dashboard** project created using **HTML, CSS, JavaScript, Bootstrap, jQuery, and DataTables**.

---

## ✨ About the Project

This project is a **school laboratory activity** that demonstrates the creation of an **Admin Dashboard** using Bootstrap and other web development libraries.

It focuses on creating a clean, responsive, and interactive dashboard interface while practicing the use of different web development technologies.

---

## Technologies Used

| Technology | Purpose |
|------------|---------|
|  **HTML** | Structure of the web page |
|  **CSS** | Styling and customization |
|  **JavaScript** | Interactive functionality |
|  **Bootstrap** | Responsive layout and UI components |
|  **jQuery** | JavaScript library for interactive elements |
|  **DataTables** | Interactive and responsive data tables |

---

##  Features

- 📊 Admin Dashboard interface
- 📱 Responsive layout using **Bootstrap**
- 📋 **DataTables** integration
- ⚡ Interactive elements using **JavaScript and jQuery**
- 🎨 Custom styling
- 🖥️ Clean and organized dashboard layout

---

## Purpose

This project was created as part of a **laboratory activity** to practice using **Bootstrap** and other web development tools in creating a functional and responsive **Admin Dashboard**.
